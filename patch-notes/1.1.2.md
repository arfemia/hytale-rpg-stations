RPG Stations is built for Hytale Update 7 (0.7.x) and needs Ziggfreed's CommonLib 2.3.0.

### Fixes

- Fixed players being disconnected when a station's summary appeared at the end of a session (the Sawmill or the Disenchanting Table, for example) on servers using an MMO Skill Tree Pro menu theme or accent colour. The summary now wears that colour on its frame.
- Fixed an issue where items whose quality had been changed lost it on a station that holds a stack, like the Sawmill, and came back as ordinary items that stacked with the rest. The station now refuses them, as it does a worn tool.
