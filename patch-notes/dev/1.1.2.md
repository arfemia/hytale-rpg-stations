Built against Ziggfreed Common 2.4.0; the manifest floor stays `>=2.3.0`, since every library call below exists there. Two bug fixes, one drop fix, and glue moved onto the library. The api artifact ships as `rpg-stations-api-1.1.2.jar` with the contract still at 10.

- **The summary's decorate hook is handed the frame.** `SummaryDecorateContext.rootSelector()` now names `#RpgStationSummaryRoot #Content` (`StationSummaryHud.decorateContext`, `FRAME_SEL`), the element carrying the frame's Background, where the card colour already lands after the hook. It named the bare root, which has no Background, so a consumer's `.Background.Color` tint made the client drop the player ("Failed to apply CustomUI HUD commands"). No api member changed; the contract stays 10. Test: `StationSummaryHudTest`.
- **A count pile refuses a re-qualified stack.** `StationCustody.carriesInstanceData(ItemStack)` now also reads whether the stack's quality index differs from its item's (try-guarded; an unreadable quality is bare on that axis), so a socket whose capacity is above one refuses such a stack through the same path as a wear-tracking tool or a stack with metadata. Before, the pile kept only the id and count and handed back `new ItemStack(id, qty)`, so the quality was lost and the stack merged with plain ones. The pure core gained a `requalified` argument; the three-argument form delegates `false`.
- **Ground drops go through the library.** `util.ItemDropUtil.dropAtBlock` keeps the station's ground (block centre, one block up) and spawns through `NativeLootService.spawnInWorld`: the tick-safe pair form with a `CommandBuffer`, the one-accessor form without, which re-queues a spawn the store refuses mid-tick onto the world thread, so that drop lands a tick later instead of being lost. The caller-frame diagnostic is gone.
- **The validator's lang check is the library's.** `StationValidator` passes `TextKeyAudit.liveCatalogue()` for `MISSING_NAME_LANG` and `MISSING_DESC_LANG`; `langKeyKnownLive` and the hand-kept `i18n.RpgStationsLangKeys` are deleted. The check fails open while no catalogue is loaded, and it accepts a key found under any loaded namespace.
- **Glue on library calls.** `StationBlockFacing.yawRadians` reads `BlockOps.rotationIndexAt`; `StationHoldController.releaseHold` calls `NativeEffectUtil.remove`; `StationService.toast` sends through `Notify.def` (the same packet); `StationValidator.itemKnownLive` asks `ItemIds.loaded`; the plugin's first log line goes through `util.Log`.
- **Dead code removed.** `util.Permissions`, `StationValidator.checkDuplicateFloorMins` (the library's roll audit owns `LOOT_DUPLICATE_FLOOR`), `StationCatalog.allFlairIds`, `StationPacing.laddersOf`, `StationService.knownStationBlockCount`, `StationStructures.pendingCount`, `StationRewardKinds.kindIds`, `ContributionChannelRegistryImpl.isDeclared` (never on the api interface) and the two interactions' `getCODEC` (registration uses the `CODEC` field).
- **The api jar is 1.1.2.** The api artifact carries the release version; `RpgStationsApi.apiVersion()` stays 10.
