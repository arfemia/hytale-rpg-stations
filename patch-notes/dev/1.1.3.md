Built against Ziggfreed Common 2.5.0; the manifest floor stays `>=2.3.0`. One recipe fix and nothing else: no code changes, and the api artifact ships as `rpg-stations-api-1.1.3.jar` with the contract still at 10.

- **Fixed: the Greater Disenchanting Table's recipe asks for an item players can get.** `Server/Item/Items/RPG_Station_Disenchanting_Table_Greater.json`'s `Recipe` takes 12 `Ingredient_Spider_Silk` (vanilla's drop from `Drop_Spider_Cave`, `Drop_Spider_Cave_Spiderling` and `Drop_Goblin_Burner`, and in the Hollows' ancient chest) in place of 6 `Ingredient_Bolt_Silk`. Vanilla crafts the bolt only at `Loombench`, and `Bench_Loom` is a `Developer` quality item on Update 7, so the table could not be made. No vanilla item is overridden.
