- **The session summary HUD sits on CommonLib's boxed panel frame.** `Pages/RpgStationSummary.ui` draws its panel in `$F.@ZigPanelFrame`, where it drew `@ZigDecoratedFrame`. CommonLib 3.0.0 makes its decorated frame the band every page sits on (a blur and a scrim over the whole screen, then a wide band), which a HUD must never draw during play; its panel frame is the boxed frame the summary always wore, unchanged, so the summary looks as it did. `#RpgStationSummaryRoot #Content` still carries the patch a tint multiplies, so the card colour (`SummaryHud.Color`) and a listening mod's `SummaryEnricherRegistry.decorate` hook (`SummaryDecorateContext.rootSelector()`) land exactly where they did, and the api is untouched. Test: `StationSummaryHudTest.aListeningModsThemeLandsOnTheElementCarryingTheBackground` reads the panel frame and holds the document to it.
- **The multi-output picker sits on CommonLib's band and wears its header tabs.** `Pages/RpgStationPicker.ui` is on `@ZigDecoratedFrame`, the band, and since the band's head and foot reach 78 above and below the page's box, the box no longer follows its content: `RpgStationPickerPage` sets `#RpgStationPickerRoot`'s Anchor from `PickerCategories.boxHeight` (the title, the hint and the cards, the list capped at five and a half cards and scrolling past them, so the tallest box and its band fit a 1080 screen). Each card (`Pages/RpgStationPickerTab.ui`, same ids) takes CommonLib's header tab by name, `ZigViewTabStyle` for its button and `ZigViewTabLabelStyle` for its name, its cost line the kit's caption and its lock reason the caption in the danger tone; the two documents spell no colour. A locked card is disabled through `.Disabled`, the property the game's own pages set, where it wrote `.Enabled`, which the client does not know (no station produces a locked category yet). Test: `RpgStationPickerPageTest` holds the box's height to the two documents and the tallest box to a 1080 screen.
- **A stamp entry on a mirrored stat is warned.** `StationValidator.checkStamp` reports `MIRRORED_STAT_ON_GEAR` (a WARNING, CommonLib's gear set audit's own token, so one filter covers a stamp entry and a gear set tier line) for each stat an inline `Stamp.Stats.Entries` entry writes (`Stat`, then each `AlsoStats` id) that CommonLib's `MirroredStats` claims: a stat whose every reading takes a record its owner keeps, so the line a stamp writes onto the item does nothing. The line names the station (or action asset, or extension), the step, the entry and the stat, with the owner's own reason (`Claim.why()`). The one read is `MirroredStats.claimOf`, asked live in both passes, so a stat nobody claims is no finding and no list of claimed stats lives in this mod; a per-fold pass run before a later layer's claim stays quiet where the full pass names it. A stamp's named `Stats.Pool` is not walked: its entries belong to the pool, not to a station. `MirroredStats` is CommonLib 3.0.0's, one more reason the floor moves at the seam (below). Test: `StationValidatorTest.stampEntryOnAMirroredStat_warnsThatCodeAndAPlainStatNone`.
- The manifest's `Ziggfreed:ZiggfreedCommon` floor goes to 3.0.0 at the release seam, once the library carries that version: an older library's `ZigFrames.ui` has no `@ZigPanelFrame`, and the client refuses a document that names one it lacks. Until then the floor stays where `ManifestTargetTest` holds it, admitting the library this build compiles against.
