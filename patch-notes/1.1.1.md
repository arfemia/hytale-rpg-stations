RPG Stations for Hytale Update 7. Nothing about how the stations work changes. Requires ZiggfreedCommon 2.3.0.

- **Runs on Update 7 (0.7.x) servers.** Rebuilt for the new server line, so a 0.7 server loads it without the outdated-mod warning.
- **Needs ZiggfreedCommon 2.3.0, the library's Update 7 build.** With an older ZiggfreedCommon installed, the server now refuses to load RPG Stations and names the library to update, rather than running it on a library that is quietly broken on Update 7.
- **No station warning for content made for a mod you don't have.** If a pack's stations post to a mod that isn't installed on your server, the station check that runs when the first player joins no longer warns about it. A misspelt channel of a mod you do have installed still gets its warning.
